Create a premium, modern, high-end digital agency website for a technology + design studio.

The website should feel like a combination of:

* premium creative agency
* modern product studio
* UI/UX design agency
* software development studio
* experimental digital experience

Do NOT make it look like a generic SaaS landing page or a basic freelancer portfolio.

## Core Brand Message

The main hero statement should be:

“We bring your ideas to digital life.”

Supporting copy:

“We design, build, and launch digital experiences that turn ambitious ideas into products people actually want to use.”

Primary CTA:
“Start a project”

Secondary CTA:
“View our work”

The overall visual language should communicate:

* creativity
* technical capability
* premium design
* confidence
* experimentation
* strong visual storytelling

---

# VISUAL STYLE

Use a dark, sophisticated visual system.

Background:

* near-black / charcoal (#111111 or similar)
* subtle gradients
* very subtle noise/grain texture
* thin dark-gray borders

Typography:

* modern geometric sans-serif
* large bold headlines
* tight typography
* strong contrast between headline and supporting text

Use a restrained color palette:

* black / charcoal
* white
* gray
* one subtle accent color such as electric blue, cyan, violet, or lime

Do not overuse the accent color.

The website should have generous whitespace and feel expensive.

Use large typography and editorial-style layouts.

---

# HERO SECTION — MOST IMPORTANT

Create a full-screen hero section.

The hero should NOT simply have a large image on the right.

Instead, create a layered composition where multiple project preview images/cards exist in the background around the main headline.

The project previews should feel like floating pieces of work.

Example composition:

```
             PROJECT 01

   PROJECT 02          PROJECT 03


          MAIN HERO TEXT


             PROJECT 04
```

The projects should sit BEHIND the main hero content.

The main headline and CTA should always remain the visual focus.

## Project background behavior

At the beginning of the hero section:

* project previews are slightly blurred
* opacity around 30–45%
* slightly smaller
* slightly desaturated
* some projects are partially outside the viewport
* cards have different rotations
* cards have different sizes
* cards have different depths
* some cards overlap each other

The projects should feel like they are already existing in the background rather than appearing suddenly.

As the user scrolls:

1. blur gradually decreases
2. opacity increases
3. project cards slowly scale up
4. cards move toward their final positions
5. rotations subtly straighten
6. colors become more visible
7. project images become sharper
8. the overall composition becomes clearer

The scroll interaction should feel like:

“discovering ideas → bringing them into focus → bringing them to life”

Use smooth scroll-linked animation.

Do NOT make the movement exaggerated or gimmicky.

The animation should feel premium and cinematic.

The project layer should use a lower z-index.

The hero text should remain above the project layer.

Conceptually:

PROJECTS
z-index: 1

HERO CONTENT
z-index: 10

# RESPONSIVE DESIGN

Design desktop first at approximately 1440px width.

Also create responsive layouts for:

Tablet: 1024px
Mobile: 390px

On mobile, the floating project composition should adapt rather than simply shrinking.

Use 2–3 project cards around the hero instead of 5–6.

The headline should remain the primary focus.

Make sure the contact form, navigation and project sections work perfectly on mobile.

# IMPORTANT CREATIVE DIRECTION

The website should NOT look like a template.

It should feel like a real creative technology studio with a strong visual identity.

The signature idea is:

“Your ideas are everywhere around you, and we bring them into focus.”

The blurred projects behind the hero should visually communicate that idea.

Start with uncertainty and blurred possibilities.

As the user scrolls, the projects become sharper and clearer.

The final message should feel like:

“We bring your ideas to digital life.”

Prioritize visual hierarchy, typography, composition, whitespace and interaction quality over adding unnecessary UI elements.
